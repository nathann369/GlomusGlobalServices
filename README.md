## Getting Started

1. Run `npm install`
2. Run `npm run dev`

## Deploy to GitHub Pages

Push the repository to GitHub using the `main` branch. The included GitHub Actions workflow builds and deploys the site automatically on every push.

In the repository on GitHub, open **Settings > Pages** and set **Source** to **GitHub Actions**. After the workflow finishes, GitHub will show the published Pages URL in that section and in the workflow run summary.
